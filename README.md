# BookMyShow - Movie Ticket Booking Application

## Project Overview

BookMyShow is a movie ticket booking application developed using Microsoft Power Apps. The application allows users to register and log in, browse movies, select seats, book movie tickets, order food and beverages, and view available offers.

Power Automate is used to automate business processes such as booking confirmations and email notifications. The project demonstrates practical implementation of Microsoft Power Platform components including Canvas Apps, Power Automate, SharePoint, Power Fx, galleries, forms, collections, and controls.

## Power Automate

Power Automate is used to automate important processes in the application.

### Booking Confirmation

User books a movie ticket in Power Apps.

Power Apps → Power Automate → Process Booking → Send Confirmation Email

### Food Order Notification

User places a food or beverage order.

Power Apps → Power Automate → Process Order → Send Email Notification
